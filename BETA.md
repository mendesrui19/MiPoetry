# MiPoetry — Guia para testadores (beta)

Obrigado por testares a app!

**Link:** [https://poemas-silk.vercel.app](https://poemas-silk.vercel.app)

## Entrar na app

1. Abre o link que te enviámos no telemóvel (Safari ou Chrome).
2. **Criar conta** → `/auth/signup` com email, palavra-passe e nome de utilizador.
3. Ou **Entrar** se já tiveres conta.

**Opcional:** no iPhone/Android, usa *Adicionar ao ecrã inicial* para instalar como app (PWA).

## O que testar

| Área | O que fazer |
|------|-------------|
| **Registo / login** | Criar conta nova, sair e voltar a entrar |
| **Escrever** | Novo poema, rascunho, publicar (Público / Amigos / Privado) |
| **Feed** | Ver poemas de quem segues (tab Feed) |
| **Descobrir** | Antologias, hashtags, poemas em destaque |
| **Perfil** | Editar bio, avatar, ver os teus poemas e rascunhos |
| **Antologias** | Criar livro em Livros; abrir link público de um livro |
| **Social** | Seguir autores, aplausos, comentários, guardar poemas |
